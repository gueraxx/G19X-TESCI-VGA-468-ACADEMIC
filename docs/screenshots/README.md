## Cómo tomarlas

1. Abre el navegador en pantalla completa (F11)
2. Ve a la página que quieres capturar
3. Presiona `Windows + Shift + S` (Windows) o `Cmd + Shift + 4` (Mac)
4. Recorta y guarda con el nombre de la tabla
5. Optimiza con [TinyPNG](https://tinypng.com/) antes de subir

## Dimensiones recomendadas

- **Ancho:** 1600-1920 px
- **Formato:** PNG
- **Peso:** < 500 KB cada una
